# AI-Assisted Development — Working Principle

This note explains how AI-assisted implementation is represented in this portfolio.

## Principle

AI is used as an engineering productivity tool for tasks such as:

- software scaffolding
- implementation drafts
- refactoring
- documentation
- repetitive code
- test scaffolding
- debugging support
- comparing possible technical approaches

AI assistance does not replace responsibility for the real system.

For the projects in this portfolio, the engineering responsibility emphasized is:

1. understanding the physical and operational problem
2. identifying system interfaces
3. choosing an integration architecture
4. reviewing/adapting implementation
5. connecting to real sensors/controllers/vehicles
6. testing behavior
7. diagnosing failures
8. validating the solution against the real requirement

## Why the portfolio is structured as case studies

Several repositories used during these projects contain:

- vendor/upstream code
- experimental prototypes
- private infrastructure details
- confidential industrial data
- AI-assisted implementation
- historical development artifacts

Publishing those repositories directly would give a misleading picture of authorship and engineering ownership.

The public portfolio therefore focuses on the parts that can be accurately attributed and technically defended:
**architecture, integration, troubleshooting, validation and results.**
